# 日期命名的 Markdown 记录

每日本地文件 `userdata/study-records/YYYY-MM-DD.md`。日期和时区取朋友电脑，工具不接受模型虚构的作答日期。当天多次学习追加，不覆盖原有内容。新写入前备份前一版本到 `userdata/backups`，写入用锁与原子替换。

每条记录有可读的标题、原始作答或 AI 反馈、教材引文与下次复测日期；其后的折叠块保存标准 JSON，供下次会话恢复。两部分一起存放在同一 MD 中，没有另一个不可见的个人记录数据库。

可以在结构块外自由补个人笔记，后续追加会保留。可读显示是写入时快照；只改显示文字不会自动修改复测状态。要修改状态，请让 Skill 追加取消/替代反馈；如直接编辑结构 JSON，需保留合法格式、ID、日期和引用信息。损坏时工具报错并保留文件，不静默丢弃记录。

事件类型：attempt、feedback、note、cancel，以及V1.2的study。feedback_format=2，关联原始attempt，保存完整参考答案及性质、版本化要点清单、五种状态、学生原话与教材逐字证据。使用提示或本次作答前看过答案的attempt不能标记independent。引用存在只能证明出处，模型仍需判断是否支持反馈。

复测按知识点名称（未提供时按题目 ID）合并，初始采用 1、3、7、14、30 天间隔，允许在反馈中明确 next_review 覆盖；失败或提示后可答默认次日。当天反复答同一考点不增加跨日成功次数。系统不自动宣称已完成迁移或稳定掌握。

取消错误反馈后从其余记录重建。缓存丢失不影响重建；删除或修改个人文件会影响后续状态，请备份 `userdata`。升级时先复制备份到新版本，再运行 `review --all` 核对任务。

## 自动错题本

反馈后生成 `userdata/mistake-book/YYYY-MM-DD.md` 与 `错题索引.md`。以题目聚合原题、共同案情、真实回答、参考答案、要点错因及复测。needs_work/hinted自动收录，unverified进入待核实区，不增加已确认错误次数；仅漏写非必要扩展不收错题。相同请求ID重试不追加；相同attempt的最新有效反馈只计一次，取消后重算。

至少两个不同日期、晚于最近出错日期、无提示且覆盖原错误点的独立复测才显示已巩固；当天多次重答不累加，后续出错重新打开。此状态是练习规则，不是学习效果保证。查询 `mistakes` 默认隐藏答案，`--details`才返回完整历史。

错题本可用 `mistakes --rebuild` 重建。生成页不供手改；若检测到手改会拒绝覆盖并返回警告，原始日志仍保存。先把手改内容转存学习日志，再备份/移开修改页及视图清单后重建。不要删除study-records来重置视图。

V1.0日志schema_version=1仍可读；缺失的答案、要点和错因不会自动补造。V1.1保留同一事件容器，新增字段不改变日期文件命名。

## V1.2学习状态

study.action包括viewed、learned、skipped、task_done。学习卡可记录正文展示与自报背完；自测和复测必须实际作答反馈，不能靠task_done勾选通过。任务/自测分配文件不是独立学习事实数据库。误报完成或跳过可cancel对应study事件；取消不抹去实际看过正文的背景。

背诵与每日自测反馈保留card_refs、practice_kind和冻结要点版本，部分要点正确不等于整卡通过。recitation-review从有效日志重建全卡覆盖与跨日通过；旧V1.0/V1.1记录缺背诵字段时显示未记录，不猜测学习经历。新事件由V1.2读取，不用旧程序写回新版userdata。
