# V1.1 修改方案：要点判定、答案反馈、错题本与资料管理

初稿：2026-11-11；实施更新：2026-11-13。状态：按本方案接入V1.1代码、Skill与知识库，V1.0发行包保留。实现与外部验证边界见 [验证记录](verification.md)。

V1.1已从用户指定目录重新导入21份Markdown、150张图片和1份来源PDF；包含合并讲义、两份中英文对照资料、讲义真题重点清单和重点批注版。详细清单、页码规则和链接处理见 [知识库更新清单](v1.1-knowledge-base.md)。当前索引5,504块，原始E盘资料不修改。

## 要解决的问题

V1.0 的 Skill 把作答后读取参考答案写为“可使用”，没有要求同一轮回复展示答案。截图中模型给出了判定、遗漏和教材引用，却把“查看参考答案”放进下一步选项，使用者还要追问。

已检查本地题库：截图对应的2023年“个人所得税综合所得的计算规则”有配套参考答案，当前状态为 `source_reference_not_official`。因此该题应在判定后自动展示题库参考答案，不能称为校方官方标准答案。

## 用户看到的固定顺序

> **简短判定 → 参考答案 → 对照分析 → 复习安排**

一次回复完成，默认不再询问“是否要看参考答案”。使用者明确要求只判分、先给提示或继续盲测时，以该次要求为准。

1. **判定**：一句话说明正确、部分正确、存在关键错误或暂不能可靠判定。没有评分细则不伪装官方评分。详细理由留在答案之后。
2. **参考答案**：给出可独立阅读的完整答题稿，标明来自题库还是由 AI 根据教材整理。不能只给几个关键词、教材位置或“可继续查看”的选项。
3. **对照分析**：按答题要点展示“你的作答 → 覆盖状态 → 需要补充或修正”，优先解释关键遗漏，避免把完整参考答案重复一遍。
4. **复习安排**：简短指出下次重点和日期；已成功保存时提示记录文件名，符合条件时提示“已自动收录错题本”。不展开权限模式、工作区或命令行说明。

## 答案来源的选择

| 情况 | V1.1 默认行为 | 展示标签 |
| --- | --- | --- |
| 题库有与当前题匹配的完整参考答案 | 读取并展示原有答案，保留其内容与来源性质 | 参考答案｜题库已有 |
| 题库没有参考答案 | 检索本地教材，核对定义、条件、例外与题目情境，整理完整答题稿并附出处 | 参考答案｜AI依据教材整理，非官方 |
| 题库答案有截断、缺漏或与教材冲突 | 原答案与教材补充分别标明，不静默改写原答案；不直接用有争议内容判错 | 题库参考答案＋教材补充／待核实 |
| 本地教材证据不足或原题缺必要材料 | 给出有依据的部分，并明确缺口；不生成假装完整的答案，判定可保留 | 参考答案暂不完整｜资料不足 |

“标准答案”仅在官方来源性质实际核验后使用。当前截图参考答案和模型生成答案不能因展示位置改变就升级为官方标准答案。

题库没有参考答案，不等于可以直接凭模型记忆答题；生成答案应有本地教材证据。也不能把使用者的原始回答换个说法当作独立参考答案。

## 按答题要点判定

本项为本轮新增优化，仅加入此前建议中的第一项。

### 先建立依据，再逐点核对

以题目要求、可用参考答案和核对过的教材建立本题答题要点清单，然后对照真实作答；不能仅凭答案长短、关键词数量或整体印象下结论，也不能根据学生回答临时改出一套有利于原判断的标准。

每个要点记录：稳定要点ID、要点内容、所属题目、核心/补充性质、必要条件或边界、参考答案或教材出处，以及本次要点清单版本。模型整理的要点明确标为训练核对依据，不冒称官方评分细则。教材或答案版本变化时重新核对，原作答仍保留当时的清单版本。

### 每个要点采用五种状态

| 状态 | 判定含义 |
| --- | --- |
| 已覆盖 | 意思和必要条件正确，可接受有依据的同义表述或不同论证路径 |
| 部分覆盖 | 已涉及该点，但必要条件、步骤或说明尚不完整 |
| 遗漏 | 题目要求的必要要点在作答中没有出现 |
| 错误 | 作答对该点给出不成立的概念、条件、推理或结论 |
| 待核实 | 来源冲突、原题不完整或证据不足，暂不能可靠裁定 |

逐点判定保存使用者作答中对应的原话或位置、判断理由和依据；“遗漏”应明确表示未找到对应内容，不能虚构一段用户原话。提到了关键词不等于已覆盖；措辞与参考答案不同也不等于错误。

只把与本题要求相称的核心要点纳入必要覆盖范围。教材延伸知识、例外背景或更高阶讨论可以作为补充，但不因使用者未写这些扩展内容就判为遗漏。同一错误影响多个相邻要点时说明关联，避免重复惩罚或夸大问题。

### 汇总与错题本联动

整体判定依据逐点结果形成：核心内容已覆盖且无实质错误，可判正确；关键要点部分覆盖或遗漏，判部分正确；存在关键概念/推理错误，明确指出；核心争议待核实时保留整体判断。没有正式分值分配依据时不把要点数量机械换算成精确分数。

错题本的收录理由直接关联具体要点ID与错误/遗漏内容，不只保存“回答不好”或一个总分。无害措辞差异和非必要扩展不触发错题；待核实问题不自动计为已确认错误。后续复测重点检查原先未覆盖的核心要点。

对外展示顺序仍为“简短判定 → 完整参考答案 → 要点对照分析 → 复习安排”，要点清单不在测试作答前展示。日期Markdown同时保存本次清单、版本、逐点状态、原话及依据，便于回顾和更正。

## 内部执行流程

```text
收到使用者作答
    ↓
保存原始 attempt，保留是否用过提示
    ↓
自动读取该题参考答案及来源状态
    ├─ 有完整答案：形成题库答案稿，核对必要的教材依据
    └─ 无完整答案：检索教材 → 核对原文 → 生成有引用的答案稿
    ↓
以答案稿、教材依据和题目要求建立要点清单
    ↓
逐点核对：已覆盖／部分覆盖／遗漏／错误／待核实
    ↓
汇总整体判定与应收录错题的具体原因
    ↓
同一回复：判定 → 答案稿 → 对照分析 → 复习安排
    ↓
把判定、实际展示的答案、来源、分析和复测安排追加到每日 MD
    ↓
从有效反馈自动更新错题本与复测状态
```

内部先准备依据再判定，避免凭印象先下结论；对外仍按“判定在前、参考答案其次、分析随后”呈现。实际写入可在回复前完成，只有确认写入成功才显示“已记录”。

测试模式保持原有边界：使用者提交作答前不读取或展示答案；提交之后自动展示，不影响原始作答独立性的记录。看过答案后的重答，不能再视作同一题首次独立诊断；跨日复测另行记录。

## 每日 Markdown 同时保留答案

沿用 `userdata/study-records/YYYY-MM-DD.md`，同日追加，保留旧记录与手工笔记。新反馈保存：

- 简短判定，以及对应的原始作答事件 ID。
- 本次实际展示的参考答案全文。
- 答案来源类型、题库与答案版本，或教材引用块、资料哈希和引用位置。
- 对照分析、待核实问题和下次复测日期。
- 本次答题要点清单及版本，每个要点的覆盖状态、对应作答原话、理由与依据。

不能只在聊天里展示答案，记录文件却只剩下分数与遗漏；也不把 AI 拟答写回原始题库，覆盖其“无参考答案”状态。后续复用拟答需另行核验与版本管理。

## 自动错题本

### 哪些题自动收录

每次完成作答反馈后自动处理，无需使用者另外说“加入错题本”。使用者明确要求不收录时尊重该次指令。

| 作答情况 | 是否收录 | 分类 |
| --- | --- | --- |
| 不会作答、核心概念错误、结论错误 | 是 | 不会／理解错误 |
| 主要方向正确，但遗漏重要条件、步骤或答题要点 | 是 | 要点遗漏／方法不完整 |
| 经提示或查看讲解后才答对 | 是 | 依赖提示，需独立复测 |
| 独立作答已覆盖核心要点，仅有不影响含义的措辞差异 | 否 | 正常学习记录 |
| 原题、参考答案或教材证据不足，暂不能可靠判断 | 暂不计为错题 | 待核实；保留原因 |

沿用 `needs_work`、`hinted`、`independent` 等作答状态，新增具体收录理由和对应遗漏点；不能只因为 AI 估分偏低就收录，也不能因为估分较高而忽略关键错误。表达方式不同但有教材依据的回答应允许成立。

### 每道错题保存什么

题目完整 ID、题库与版本、完整题干及共同案情、每次原始作答、判定、错误/遗漏点、实际展示的参考答案及来源、关联知识点与教材出处、作答日期、有效错误次数、复测历史、当前状态和下次复测日期。

同一道题多次答不好，在总览中仍为一条题目，累计各次作答与错误点；日记录保留每次经历。同一次写入重试不重复计数。不同题库中近似或改编题保留原 ID，可关联但不静默合并。

### 记录放在哪里

```text
userdata/
  study-records/
    2026-11-12.md             当日作答、答案、反馈和复测事件：事实来源
  mistake-book/
    2026-11-12.md             从当日有效记录生成的错题内容
    2026-11-13.md
    错题索引.md              按题目汇总，筛选待复习／复测中／已巩固／待核实
```

日期示例只表示命名方式，运行时取朋友电脑的本地日期。每日错题文件可直接阅读题目、自己的回答、参考答案和错误分析，不是只有 ID 的清单。

`study-records` 仍是唯一的学习事实来源；错题日期页与索引是可重建的派生视图，不另建一套必须同时修改的个人数据库。错题视图由工具维护，个人补充笔记写入日期学习记录。视图写入失败时保留日志，下一次重建；未成功前不提示“错题本已更新”。

### 怎样复习与移出待复习列表

支持自然语言入口：“今天先练错题”“复习个人所得税的错题”“列出反复做错的题”“查看已巩固的错题”。默认优先安排到期错题，并结合错误反复次数与知识前置关系选择，不能只追求刷题数量。

初始状态规则：

```text
新收录／再次答不好 → 待复习
一次无提示闭卷复测通过 → 复测中
两次不同日期的无提示闭卷复测通过，均覆盖原错误点 → 已巩固
再次出现关键错误或依赖提示 → 回到待复习
```

这里的“已巩固”是本错题的操作状态，不等于证明整个知识点永久掌握。看着答案重述、当天重复背诵或只改变几个数字的变式不能制造跨日通过次数。复测出题时隐藏历史答案和错误解析，提交之后再展示。

已巩固的题保留全部历史，仅移出默认待复习列表，不删除。存在待核实争议时不硬判错；后续取消错误反馈或补充更正事件后，重新计算错题收录、错误次数与状态，避免已撤销的判定继续影响复习。

### 与旧记录的衔接

V1.0已有 `needs_work` 或 `hinted` 的有效反馈，可在首次升级时自动建立错题索引，并链接原始日期日志。旧记录没有参考答案快照或具体错因时标注缺失，不编造历史答案、原因或已巩固状态。待复习与已通过复测的信息只依据可验证的历史事件恢复；资料版本不匹配时标为待核实。

## 随包提供 MinerU 资料转换能力

### 交付目标

朋友后续拿到新的教材、讲义、题集或扫描资料时，可以在 DeepSeek Harness 中直接要求：“把这份资料转换并加入我的知识库”。包内提供 MinerU 接入说明、转换入口、环境检测/准备工具和导入适配器，不要求她手动复制 CLI 输出、迁移图片或重写资料索引。

本机只读核对结果：已安装 MinerU 4.1.7，CLI报告Python 3.14.2。该结果仅作为后续兼容验证基线，不能证明同一环境直接复制到朋友电脑就可运行。

MinerU 的 Skill 说明、命令程序、解析依赖与模型资源分别管理；不能只复制 `SKILL.md` 或本机 `.local/bin/mineru.exe` 就宣称含有完整解析能力。现有 V1.0 工具运行环境只含 Python 标准库，不能自动视为已装有 MinerU。

### 包内组成与首次准备

- **主包**：备考 Skill、MinerU 转换接入说明、转换/导入工具、环境检测和准备入口，继续包含原有教材、题库及索引。
- **转换环境**：使用独立 MinerU 环境和锁定依赖，与备考工具的轻量运行环境隔离；检查版本与可用解析引擎。
- **解析资源**：按朋友电脑硬件验证适合的本地引擎与模型。可作为匹配的增强资源包随主包一起交付，也可首次联网下载；如需完全离线转换，必须同时交付并验证依赖与模型资源。
- **第三方说明**：附所分发版本的许可证、依赖来源、版本与校验清单；项目自己的代码许可不替代第三方许可。

默认设计为本地优先、允许首次联网准备环境；这不等于默认上传文件到云端。模型和依赖下载所需体积、支持的格式和处理速度，以目标设备及选定版本验收结果为准，本方案不承诺任意 Windows 电脑均可直接高质量离线解析。

### 转换后自动接入学习流程

```text
朋友指定新资料
    ↓
选择或确认用途：教材／讲义／题集／参考答案
    ↓
检查 MinerU 环境与所需解析能力
    ↓
转换为 Markdown，保留页序、正文、表格、公式及图片附件
    ↓
显示转换完整度、识别警告和导入预览
    ├─ 教材／讲义：建立来源与版本 → 导入正文 → 更新教材检索索引
    ├─ 题集：拆分题干、案情和答案 → 检查配对与缺失 → 导入对应题库
    └─ 参考答案：确认对应题目 → 建立答案关联，不混入普通教材检索
    ↓
反馈新增数量与待核实项，后续讲解、拟答和错题复习可使用新资料
```

MinerU 负责识别转换，不替代题库整理和教材检索。不能把“输出了一份 Markdown”当作“题目和答案已正确入库”。普通 Markdown/TXT 直接读取，不重复 OCR；PDF、图片及其他格式走选定版本实际支持的解析路径。

### 数据与可靠性

- 原始资料、转换正文和附件保存在朋友电脑的用户资料目录；清单以相对路径、来源 ID、文件哈希及解析版本关联，程序升级不覆盖这些资料。
- 转换导出需完成所选范围，整份导入不能误把默认前几页或截断内容当全文。校验页序、附件存在性与输出完整性；复杂表格、公式和低质量扫描提示人工抽查。
- MinerU 返回的文档定位保留为解析溯源，同时把必要正文和图片冻结为包内文件；教材引用不只依赖某台电脑的临时缓存或绝对路径。
- 新增教材采用通用资料导入与来源角色配置，解除 V1.0 导入脚本只识别四本固定教材的限制；新增讲义明确其性质与优先级，不能冒充指定教材或官方答案。
- 转换任务保留处理中、失败和完成状态，失败后能从有效进度继续；重复提交相同资料提示去重，质量调整或内容修订作为新版本处理，不覆盖旧学习记录的依据。
- 本地解析不可用时展示可用选项，不静默上传原文或切换低质量输出。远程解析仅在朋友明确选择后执行，由她自行配置所需账号/密钥；发给朋友的包不含制作者凭据、缓存或服务配置。
- 完成转换本身不产生作答或错题记录。只有实际练习反馈才能触发自动错题本；导入结果可另记在当日学习日志中。

## 验收场景

1. **截图中的有答案题**：提交作答后，同一回复先判定，再直接展示题库参考答案，最后分析；无“要不要查看答案”的追问。
2. **没有答案的题**：使用一题现有2025/2026题目，展示带教材出处的完整 AI 参考答案，再分析；不引用错配的旧答案。
3. **答案不完整或冲突**：清楚区分原答案、教材补充与待核实处，不伪装成统一官方结论。
4. **教材支持不足**：不虚构规则或引文，不为了固定模板强行给完整答案和确定判分。
5. **测试前后边界**：作答前不泄露答案，作答后默认自动展示；明确要求继续盲测时尊重该例外。
6. **记录与兼容**：MD包含本次实际答案及来源；同日多次作答、手工笔记、旧记录读取和复测恢复正常。
7. **宿主真实对话**：在已部署的 DeepSeek Harness 中复现有答案、无答案两种对话，确认模型实际遵循输出顺序。单元测试通过不替代此项。
8. **自动错题收录**：错误、重要遗漏和依赖提示均自动收录；无害措辞差异不收录，证据不足单列待核实。
9. **去重与记录**：同题再次答错只增加对应历史与有效次数；重复请求不增加次数，MD可直接读到题目、作答、答案和错因。
10. **复测状态**：看答案后的当日重答不计跨日成功；两次不同日期无提示通过后移入已巩固，历史不删除，再错可重新进入待复习。
11. **恢复与更正**：删除派生错题视图后可从日期日志重建；取消错误反馈后，错误次数和状态随之修正，旧记录缺失字段不被补造。
12. **新资料转换入库**：在朋友同类 Windows 环境中，用小型文本PDF、扫描PDF和包含表格/公式的样本验证转换、页序及附件保存；新资料能被搜索、引用，不只在转换目录中出现。
13. **题集与答案导入**：转换后的题干、案情和参考答案配对正确，无答案题不补造来源答案；重复导入与失败重试不创建重复题库。
14. **独立部署**：不依赖制作者的 MinerU 安装位置或缓存；完整转换资源包通过换目录及离线转换检查，未附资源的主包明确提示首次准备；不自动上传文件。
15. **新版知识库**：新增讲义与中英文要点可检索、引用；题库与参考答案来源未错配，批注副本不冒充独立证据。
16. **分册定位与换机链接**：合并讲义跨分册引用不串页，原件缺页保留提示；附件和正文跳转不依赖制作者机器路径，原有日期日志及错题记录保留其引用版本。
17. **讲义重点资料**：可由重点清单定位到批注版和原讲义，使用复习顺序标签安排专题；讲解依据可回到原文，重复正文不增加证据数量，不将高亮程度当作命题概率。
18. **要点判定**：同义正确表述判已覆盖，只提关键词但缺关键条件判部分覆盖；明确区分遗漏、错误和待核实，不能虚构用户原话。
19. **判定范围与联动**：不因缺少非必要拓展而判错，不重复惩罚同一问题；错题原因可追到具体要点和依据，MD保留清单版本与逐点结果，整体判定与这些结果一致。
