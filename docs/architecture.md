# 架构与数据边界

`Skill → 宿主的文件/命令工具 → CLI → 本地教材、题库和每日 Markdown`。

没有学习网页、后台模型服务或内置模型 SDK。默认接入 DeepSeek Harness 的标准项目 Skill 目录，调用其已有命令执行工具，因此无需实现不稳定的自定义 Cordis 工具插件。换宿主时可复用同一 CLI。

## 核心模块

| 模块 | 职责 |
| --- | --- |
| `common.py` | 项目路径边界、原子写入、写锁、文件校验 |
| `library.py` | 版本清单、跨页原文块、SQLite FTS5 中文二元词及英文检索、引文校验 |
| `materials.py` | 资料角色、链接冻结、导入与旧版资料归档 |
| `questions.py` | 题库读取、两种现有真题布局解析、原题/参考答案配对、标准题库导入 |
| `records.py` | 每日 Markdown 事件追加、备份、幂等请求、取消反馈与复测投影 |
| `feedback.py` | 参考答案快照、逐点判定校验、整体汇总和固定反馈渲染 |
| `mistakes.py` | 从有效事件重建每日错题Markdown及索引、跨日状态 |
| `mineru_adapter.py` | 独立解析环境、转换任务恢复、全文与附件导出校验 |
| `recitation.py` | 主讲义背诵卡、不可变版本、虚拟抽查题与整卡核心点覆盖投影 |
| `daily.py` | 日期Markdown任务、预算、前置条件、重排与旧自测题顺延 |
| `selftests.py` | 今日实际已背范围、冻结题目/答案/要点、预算校验与无答案出题视图 |
| `study_settings.py` / `markdown_store.py` | 生效的本机学习配置 / 保留手工文字的版本化Markdown容器 |
| `cli.py` | UTF-8 JSON 接口、统一错误与参数 |

默认检索role为textbook/lecture/bilingual_notes；未复制正文的guide可单独检索，derived_from批注不重复索引。参考答案不混入教材证据。SQLite仅保存可重建缓存，个人记录事实来源是Markdown。模型负责语义判定；代码校验逐字出处、学生引文、五态逐点结构、答案来源和汇总一致性，不以关键词命中自动批改。

原文块ID绑定来源ID、哈希和起止偏移。显示PDF物理页序和行号，不推造印刷页码；合并讲义还保存source_part、分册PDF页序、merged_page与页锚点，分册边界不跨块。资料变更先归档旧清单、原文和索引；旧块只在哈希有效的归档中读取并标historical。缺失/篡改的历史证据报错，不能替换为当前同名原文。

AI 自拟题可以导入，但必须附能在教材中逐字核对的证据。逐字匹配不能证明题目或解释正确，仍需人工核查。真题原始类型由资料清单标记，其他题库来源不会被自动改成真题。

## 分发与升级

`library`、`indexes`、`runtime`、`runtime-mineru`、`userdata`均不进入Git。私人包按校验清单打包资料与独立运行依赖，公开包没有私人教材。题库更新使用新bank ID；资料用稳定source ID更新并保留旧版，以保存历史引用。每次反馈保存题目、答案、要点和证据快照。

错题本是可重建视图，无独立事实数据库；同attempt的有效最新反馈只计一次，cancel后重新投影。手改错题视图会阻止自动覆盖，个人笔记应追加到study-records。转换任务与个人解析配置在userdata，不进发布包。MinerU依赖与核心标准库环境分开，核心检索/记录不依赖OCR模型。

V1.2新增study事件，viewed/learned与实际attempt/feedback分开。自报完成不是正确判定；取消误报后恢复学习任务，但正文曝光不可撤销。卡片、今日自测和真题用共同的知识点/来源关联，已有学习背景会保留到关联真题。未测核心点不由单题正确补造，跨日整卡通过按真实要点覆盖计算。

计划与自测试卷存日期Markdown任务快照，实际完成仍从学习日志投影；缩短时间时限定可继续的既有题目，超预算不出题。标准库工具负责确定性校验和默认回忆题，语义拟题、解释和教学安排由宿主模型与Skill承担，不另接模型API。

核心默认使用约定相对目录，`--root` 可将整个项目迁移到其他位置。`config/example.json` 是项目元数据样例，不是自动生效的运行参数；实际工具目录通过 `--root` 确定，模型参数由宿主管理。
