# 从V1.0/V1.1升级到V1.2

1. 备份整个旧项目，保留原有学习记录；将V1.2私人包解压到新目录。
2. 将旧userdata复制到新根目录。旧日期日志、导入题库和个人笔记继续可读，不从历史总分推造背诵进度。
3. 若自己新增过教材或背诵卡，另保留旧library与其清单。先核对来源ID/版本，再用资料与卡片工具导入新目录；不要直接用旧library/索引覆盖新版起步库，也不要仅搬userdata后丢弃新增资料。
4. 执行检查安装.cmd，再用tools.cmd review --all、tools.cmd mistakes --rebuild核对历史任务。用tools.cmd cards查看当前可用卡片。
5. 在Harness选择新根目录，开启新会话加载 `/tax-exam-coach`。发送“今天有30分钟，按严明讲义安排学习和背诵，背完后根据今天背的内容出题”。

V1.2仍使用schema_version=1的日期Markdown容器，新增study事件与卡片引用字段。旧版程序不认识这些新事件；升级后保留旧包用于查历史，不用旧程序写回新版userdata。

私人包不含个人配置、学习记录或OCR模型缓存。MinerU仍需使用者自行明确准备所选模型，普通转换不会自动下载或上传。
