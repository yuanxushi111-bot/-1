# 税法备考 Skill V1.1 使用教程

想跟着图看，可以打开[图文教程](user-guide-illustrated.md)或[浏览器图文版](user-guide-illustrated.html)。

适用：Windows 电脑、DeepSeek Harness、含教材的 V1.1 私人完整包。日常使用直接对话即可，后面的命令用于资料导入或排查问题。

**每天的基本用法：打开项目 → 加载 Skill → 说明今天有多久 → 先答题 → 看答案和分析 → 下次复测。**

## 1. 第一次使用：先完成这五步

### ① 解压完整包

使用文件名以 `windows-x64-private.zip` 结尾的包。公开源码包没有真实教材和完整运行环境，不能当成朋友的即用包。

解压到一个独立、可写的文件夹，例如 `D:\kaoyan-agent`。找到同时包含以下内容的那一层：

```text
kaoyan-agent/
├─ 检查安装.cmd
├─ tools.cmd
├─ tax_exam.py
├─ .dsh/
├─ library/
├─ runtime/
└─ runtime-mineru/
```

这里就是下文说的“项目根目录”。有时压缩包解压后还套着一层同名文件夹，以能看到 `tools.cmd` 的那一层为准。

### ② 准备 DeepSeek Harness

DeepSeek Harness 需单独安装。打开后，按所用版本的设置配置自己的模型连接，再选择上面的项目根目录作为工作区。

Windows 私人包已包含工具所需的 Python 和 MinerU 依赖。复习现有资料时，无需另装 Python，也无需先下载 OCR 模型。

### ③ 检查安装

双击 `检查安装.cmd`。重点查看输出中的：

```text
version: 1.1.0
ready: true
```

实际显示是 JSON，可能写成 `"version": "1.1.0"` 和 `"ready": true`。`ready: true` 表示本地教材、题库和检索工具检查通过；模型连接是否可用，还需在 Harness 中发起对话确认。

### ④ 加载 Skill

在 Harness 的新会话中输入：

```text
/tax-exam-coach
```

如果找不到入口，先检查工作区是不是包含 `tools.cmd` 的完整项目目录，以及 `.dsh/skills/tax-exam-coach/SKILL.md` 是否存在。

### ⑤ 发送第一条学习指令

下面这段可以直接复制：

> 我准备参加2027年12月的厦门大学税法学初试，现在边工作边备考。今天有30分钟。请先检查本地资料，查看有没有到期复测任务；没有的话，选一道中国税法学真题。一次只出一题，先让我独立回答，不要提前给答案。答完后按“判定、完整参考答案、要点分析、复习安排”的顺序反馈，并保存学习记录。

## 2. 每天怎样复习

### 开始时：说明时间和范围

| 今天的情况 | 可以直接这样说 |
| --- | --- |
| 只有十几分钟 | 今天只有15分钟，先复测一道到期错题，一次只出一题。 |
| 想练新题 | 今天有30分钟，给我一道国际税法学简答真题，先不显示答案。 |
| 想按薄弱点复习 | 根据已保存的记录，选一道我反复遗漏核心要点的题；先给题干，不读历史答案。 |
| 想看讲义重点 | 结合严明讲义的重点清单选一个专题，回到原讲义核对依据，再用一道题检查我是否理解。 |
| 今天只想听讲 | 切换为讲解模式，讲一道税收抵免相关题，直接给参考答案和教材依据。 |

时间是任务量偏好，当前版本不会自动计时或在后台督促。没告诉它每天能学多久，也不影响保存作答。

### 作答时：提交自己的原话

直接发送答案即可，可以分点写。不会时明确说“不会”，只记得一部分也照实回答。

如果用了提示或看过答案，请说明：

> 这次我看过提示，下面是我的回答，请按提示后作答记录。

想先得到提示、暂时不看完整答案时，可以说：

> 先给一个小提示，不要展开参考答案，我想再试一次。

### 答完后：看这四部分

正常完整反馈的顺序是：

**简短判定 → 完整参考答案 → 要点对照分析 → 下次复习安排。**

| 题目资料情况 | 你会看到什么 |
| --- | --- |
| 题库已有参考答案 | 直接展示原答案，保留来源性质，不需要再追问“给我答案”。 |
| 题库没有参考答案 | 依据本地教材整理参考稿，标注“AI依据教材整理，非官方”，并给出处。 |
| 原答案有缺漏或与教材冲突 | 保留原答案，另列教材补充和争议，不把两种口径悄悄混在一起。 |
| 原题或教材证据不足 | 明确指出缺口，暂不作可靠判定，不强行编完整答案。 |

当前2023、2024题库有本地参考答案；2025、2026没有配套题库答案。截图转录和题集参考答案不等于校方官方标准答案。

要点分析有五种状态：已覆盖、部分覆盖、遗漏、错误、待核实。必要核心要点与补充知识分开；没写可选扩展，不应自动算作核心遗漏。没有正式评分细则时，反馈不代表官方阅卷分数。

### 结束时：确认保存结果

可以说：

> 今天先到这里。请简短列出本次薄弱点、下次复测日期和实际保存的文件位置。

确认工具返回保存成功。若只保存了学习日志、错题本更新失败，应先保留日志，再处理提示的问题。

## 3. 怎样使用自动错题本

回答存在重要错误、核心遗漏或依赖提示时，会自动收录，无需再说“加入错题本”。同一道题在索引中聚合，保留每次有效作答。

| 状态 | 含义 |
| --- | --- |
| 待复习 | 新收录、再次答不好，或仍依赖提示。 |
| 复测中 | 已有符合条件的独立复测通过，仍需后续验证。 |
| 已巩固 | 至少两个不同日期、晚于最近出错日期的无提示复测通过，并覆盖原错点。 |
| 待核实 | 资料不足、争议或版本不匹配，暂不算已确认错误。 |

看着答案重述、当天连续重答，不算跨日掌握；以后再次出错，仍可回到待复习。

常用说法：

> 今天先练到期错题，只给题干，不展示我的旧答案和解析。

> 找一道个人所得税相关的错题，等我答完再对照原错点分析。

> 列出已巩固的题目，让我选择一题抽查。

> 这条判定我有异议，请核对教材；如果原判定有误，取消原反馈并追加更正，保留原始作答。

如果明确不想收录某一次练习，可以说“这次只练习并保存日志，不收录错题本”。

## 4. 记录保存在哪里

`userdata` 在自己的项目文件夹里，第一次实际保存后会生成相应子目录。日期取电脑本地日期，下面只是命名示例：

```text
userdata/
├─ study-records/
│  └─ 2026-11-13.md       原始作答、参考答案、分析、个人笔记和复测安排
├─ mistake-book/
│  ├─ 2026-11-13.md       当日错题及复测内容
│  └─ 错题索引.md          按题目汇总的错题总览
├─ imported-banks/        后续导入的题库
├─ import-tasks/          新资料转换任务、原件副本、Markdown及图片
└─ backups/               学习日志写入前的备份
```

可用 Obsidian 或其他 Markdown 阅读器打开这些文件。想直接跳回教材，可以要求：

> 把这个判断对应的本地文件、PDF页序和原文引文列出来。

严明合并讲义的页码还需区分分册和合并页序，不能只拿一个页数去另一册查找。

个人笔记可以让 Agent 追加，也可以写在学习日志的结构化记录块外。**错题本页面由工具生成，补充笔记写学习日志；不要直接修改折叠区中的 JSON。** 备份时至少复制整个 `userdata`；若要连同自己新增的教材一起迁移，复制整个项目文件夹更省事。

学习文件保存在本机；如果 Harness 使用云端模型，必要题目、作答和教材片段会发送给所配置的学习模型。MinerU是否远程解析是另一项独立选择。

## 5. 补充教材、讲义或其他题库

### 已经是 Markdown 的教材或讲义

把文件放到自己方便找到的位置，然后在对话里给出真实路径，例如：

> 把 `D:\学习资料\新讲义.md` 作为讲义加入知识库。先预览资料名称和附件，确认无缺失后导入，再试检索一处内容。

Markdown无需OCR。正文引用的图片应一并保留，不能只复制正文后删除原图片目录。导入成功会建立本地副本和检索索引；只把文件放到某个文件夹，还不算已经入库。

### 新资料是 PDF、扫描图片或 Office 文件

加载转换 Skill：

```text
/mineru-documents
```

然后说：

> 请把 `D:\学习资料\新讲义.pdf` 转成Markdown，检查完整页序和图片；预览后作为讲义加入知识库。只用本地解析，如果缺少模型，请先告诉我需要准备什么。

转换可能需要等待。任务显示处理中时，让 Agent 继续原任务；转换完成后还需导入，不能只看到“生成Markdown”就认为入库完成。

PDF和图片可能需要另外准备识别模型，**即使flash档也可能需要资源**。包内的 `准备MinerU.cmd` 用于依赖检查/准备，不等于OCR模型已经下载完。

只有确定要联网下载basic模型并启用本地引擎时，才在项目根目录的PowerShell运行：

```powershell
& '.\runtime\python.exe' scripts/prepare_mineru.py --models basic --enable-local
```

模型体积、耗时和设备兼容性以实际准备结果为准。日常转换默认不下载模型、不自动切远程；远程解析需要自己配置服务并明确选择上传。

### 补充题库或单独的参考答案

可以添加教材习题、模拟题、自建题，也可以让 Agent 依据教材拟变式题；这些来源会与真题区分。

> 把 `D:\学习资料\模拟题.md` 整理为模拟题库，保留原题、共同案情和参考答案。没有答案就留空，不要补造。先给我导入预览。

任意布局的题集需要先整理成标准结构；PDF题集先转换，再整理。现成格式见项目 `examples/demo-bank.md` 和 `examples/demo-bank.json`，其中是软件自制演示题，不是考研资料。

单独补答案时，要求先核对对应题目，并以新题库ID保留更新版；V1.1不会原地覆盖相同ID的旧题库。AI拟题必须有教材证据，不能冒称历年真题。

## 6. 常用指令速查

| 想做什么 | 直接发送 |
| --- | --- |
| 开始当天复习 | 今天有20分钟，先查到期任务，一次出一题。 |
| 只练某一科 | 今天练国际税法学，先让我独立答。 |
| 追问依据 | 这个判断的教材原文在哪里？请给文件、页序和引文。 |
| 练专业英语 | 用中英文对照资料选一个术语，让我先用英文解释，再分析。 |
| 看严明重点 | 根据严明讲义重点清单选一个主题，回原讲义核对，再出题。 |
| 保存个人笔记 | 把下面这段作为今天的个人笔记追加，保留我的原话。 |
| 核对错题 | 查看今天是否有未成功写入的错题视图，并说明具体问题。 |
| 换新会话继续 | 从本地记录恢复复习安排，先给我到期题干，不读历史答案。 |

## 7. 遇到问题时

| 现象 | 先这样处理 |
| --- | --- |
| 找不到Skill | 核对工作区根目录、`.dsh/skills`及宿主Skill发现设置，再开新会话加载。 |
| 检查安装显示ready=false | 把具体错误交给Agent；资料变化需核对来源后重建，缺文件需恢复。 |
| 一直让我确认要不要看答案 | 提醒“按V1.1，在判定后直接给完整参考答案再分析”，并检查是否加载了旧Skill。 |
| 无题库答案 | 要求从本地教材拟答并标非官方；教材证据不足时保留待核实。 |
| 没有学习记录文件 | 核对是否实际调用保存工具并成功，聊天中说“已记录”不能代替文件写入。 |
| 日志保存了，错题本没更新 | 保留日志，检查视图是否被手改，再按错误提示修复/重建。 |
| MinerU缺模型或引擎 | 先准备所选本地资源；不要把反复重试当成已经安装成功。 |
| 转换中断或等待超时 | 根据返回的任务ID继续原转换任务；未完成前不导入部分正文。 |
| 模型连接失败 | 检查Harness里的模型配置；本地doctor通过不表示云端模型连接正常。 |

## 8. 备用命令与升级

平时可以让Agent代为运行。自己运行时，先在PowerShell进入实际项目根目录，以下路径仅为示例：

```powershell
Set-Location 'D:\kaoyan-agent'

# 检查本地资料
& '.\tools.cmd' doctor

# 到期任务与到期错题，错题列表默认不含答案
& '.\tools.cmd' review
& '.\tools.cmd' mistakes --due

# 从学习日志重建错题本；若提示手改冲突，先处理冲突
& '.\tools.cmd' mistakes --rebuild

# 检查转换环境，不代表OCR模型已就绪
& '.\tools.cmd' mineru-check
```

升级时：备份旧目录 → 把新包解压到新目录 → 复制旧 `userdata` → 核对日志和额外题库 → 在Harness切换到新版目录、开新会话加载Skill。自己导入过教材时还需保留旧项目及其 `library`，核对后将新增资料导入新版，不能只复制userdata就丢弃旧项目。

当前软件工具已经完成本地验收；真实Harness模型对话和朋友电脑上的扫描资料识别仍需实际使用确认。关于记录格式、题库格式及升级细节，见同目录的 `records.md`、`question-banks.md` 和 `upgrade-v1.1.md`。
