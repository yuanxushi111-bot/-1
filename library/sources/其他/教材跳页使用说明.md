# 教材输入页码跳转说明

打开一本教材或教材重点批注版，直接在**右上角“#”按钮左侧的常驻页码输入框**输入数字，按 **Enter** 即可跳转。输入框右侧显示总页数（如 `/ 402`）。

快捷键 **Ctrl+Shift+G** 仍可打开高级跳页弹窗，用于选择合并讲义中的分册。
也可以点击当前笔记右上角的“#”按钮，或底部状态栏的“跳页·共N页”。

页码按PDF页面顺序计算，包含封面与目录，与书上印刷页码可能不同。每页正文前可见“PDF 第N页”标记。

《严明法学讲义》默认按合并后整份文档的1—446页跳转；可以在弹窗中选取某一分册，再输入该分册内部的PDF页码。分册页码也包含该分册原有的封面。缺失的原件印刷页164—165仍未补写。

弹窗里的“上一页/下一页”调整输入数值，按“跳转”或Enter后定位。
命令面板（Ctrl+P）里也可搜索“教材页码跳转”。阅读模式与编辑模式均可使用。

若Obsidian在安装时已经打开，关闭并重新打开该资料库，或在第三方插件列表中重新启用“教材页码跳转”。快捷键冲突时，可到“设置→快捷键”搜索“输入页码跳转”重新指定。

本地插件不联网，不调用模型；仅读取当前文档页码索引并记住最近跳转的位置。
教材正文保持原有内容，新增的页码定位行以 `^textbook-page-N` 为块标识。移除插件后，定位行仍可正常阅读。
